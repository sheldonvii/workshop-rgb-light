# WLED 控制器配置与灯效通信

本文补充 [README 快速上手](../README.md#快速上手)，说明 WLED 控制器的权限配置、灯光参数、串口通信协议与故障排查。

60 颗灯带只亮前半段时，先检查控制器是否仍配置为 30 颗，再判断接线或灯带故障。首次使用先按 [USB 配置为 60 颗](prepare-wled.md) 查询；仍是 30 颗时执行独立准备脚本。控制器内部总数量和单路长度必须都为 60，只改项目配置不能完成初始化。日常启动不会刷写控制器。

## 连接与权限

已验证的控制器为 WLED-Controller-S2，固件 WLED 0.15.1，原生 USB CDC，60 颗 RGB 灯珠。首次部署先完成下面步骤，再启动 Demo。

1. 使用可传数据的 USB 线连接控制器，执行 `ls -l /dev/serial/by-id/` 查找设备。若没有串口，检查数据线、USB 端口和固件的 USB CDC 支持。
2. 检查串口所属组和运行用户权限。K3 上设备属于 `root:dialout`，首次配置执行下方命令，将实际运行 Demo 的用户加入 `dialout`。需要 sudo 认证，但不要用 sudo 运行整个 Demo。
3. 重新登录 SSH／桌面会话，再运行 `id` 确认包含 `dialout`。已运行的服务也要重启才能获得新组权限。新板子、新系统或更换运行用户时需要重新检查，同一用户日常启动和 USB 插拔无需重复配置。
4. 项目固定使用 60 颗灯珠，先完成控制器内部数量初始化，再核对 `configs/light.json` 的 `port`。优先用 `/dev/serial/by-id/…`，不要假定始终是 `/dev/ttyACM0`。启动后页面应显示控制器已连接，并现场观察整条灯带。

```bash
# 请替换为实际运行 Demo 的用户；本项目板端用户为 bianbu
sudo usermod -aG dialout bianbu
# 退出并重新登录后检查
id
ls -l /dev/serial/by-id/
test -r /dev/serial/by-id/usb-WEMOS.CC_LOLIN-S2-MINI_0-if00 && \
test -w /dev/serial/by-id/usb-WEMOS.CC_LOLIN-S2-MINI_0-if00 && echo SERIAL_ACCESS_OK
```

如果目标系统的设备所属组不是 `dialout`，请使用实际组名。使用 systemd 部署时确认 `User=` 为已授权用户；必要时配置 `SupplementaryGroups=dialout` 并重启服务。不要用 `chmod 666` 开放串口，也不要将密码写入脚本或仓库。

## 灯光配置

参数保存在 [configs/light.json](../configs/light.json)，修改后重启服务。

| 配置 | 默认值与含义 |
| --- | --- |
| `enabled` | `true`；没有实体灯带时可改成 `false`，网页和推理仍可运行 |
| `port` / `led_count` | 当前设备的固定路径 / `60`；连接时会查询 WLED，数量不一致则停止输出并提示 |
| `brightness` / `standby_brightness` | `0.10` / `0.06`；关闭电流对齐时的基础亮度 / 待机的 RGB 缩放系数 |
| `mixed_brightness` | `0.60`；同时存在多种已确认表情时的 RGB 缩放系数，省略时沿用 `brightness` |
| `group_brightness` | `[0.35, 0.60]`；关闭电流对齐时，2～3 人 / 4 人及以上同表情的亮度 |
| `standby_color` / `transition_ms` | `#EAB7CF` / `400` 毫秒；无可靠情绪时使用待机光 |
| `fps` / `keepalive_ms` | 渐变最多每秒 `30` 帧；稳定颜色每 `1000` 毫秒补发一次 |

默认启用 `current_alignment`，单一已确认情绪的目标估算电流为 220mA；全员可见、稳定且同表情时，2～3 人为 450mA，4 人及以上为 700mA。有人待确认、暂离或保留旧色时不增档。多种已确认表情保留 60% RGB 缩放，待机为粉色 `#EAB7CF`、6%。删除 `current_alignment` 可恢复百分比模式。

分区模式按画面从左到右分配等长灯区，邻接处短距离混色。60 颗灯珠、两人不同表情时各占约 30 颗；三人中相邻两人开心、一人难过时，黄光约占 40 颗、蓝光约占 20 颗，交界处以 4 颗灯珠混色。镜像开关会在下一帧调整灯区顺序。沿线颜色占比按表情人数汇总，背景保留相同比例；灯带输出条显示后端逐像素轨迹。

当前仅使用空间分区渐变，不使用整灯轮换、呼吸或频闪。

| 表情 | 灯色 | RGB 色值 |
| --- | --- | --- |
| 开心 | 日光黄 | `#FFD000` |
| 惊讶 | 琥珀橙 | `#FF780A` |
| 平静 | 青绿色 | `#00D9A6` |
| 难过 | 深蓝色 | `#246BFF` |
| 生气 | 朱红 | `#FF2010` |
| 害怕 | 紫罗兰 | `#8000FF` |
| 厌恶 | 饱和绿 | `#55DD00` |
| 轻蔑 | 玫粉色 | `#FF269C` |

## WLED 设置与供电

控制器端需预先配置灯带类型为 WS281x、颜色顺序为 GRB，数据引脚根据原理图标注设为 GPIO38，灯珠总数与单路长度均设为 60。为避免通信冲突，需关闭其他实时控制源，并将实时接收超时设为 2500 毫秒（大于后端的 1000 毫秒保活间隔）。

服务通过 USB CDC 串口与控制器交互。建立连接时，后端先发送 JSON 指令只读查询固件版本和灯珠数量，校验一致后再通过 Adalight 二进制协议连续推送颜色帧。该控制器工作电压为 5V，不可接入 12V 或 24V 电源。

当前硬件方案由 K3 的 USB 端口通过控制器向 60 颗灯带供电，受固件内置的 850mA 限流保护。实测 60 颗灯珠全亮纯黄光时，在 RGB 缩放达到约 67% 即会触及 850mA 限流线。为防止硬件限流引发亮度压缩与偏色，后端将电流对齐最高档设为 700mA，在保证辨识度的同时留出供电安全裕量。

## 运行与退出行为

系统按以下时序管理灯效状态与会话生命周期：

* **待机与离场过渡**：服务启动后或无有效识别时，灯带保持粉色待机光（`#EAB7CF`）。多人场景下每张人脸独立计时，目标离开画面后保留旧色 900 毫秒，超时后退出占比计算。当所有人离开画面，灯带在 400 毫秒内渐变回待机光。多端打开网页时，灯光控制权由首个发起体验的会话独占。
* **异常重连与退出恢复**：运行中若串口断开，服务每隔 2 秒自动重连并同步最新灯态。在网页中点击停止按钮会释放摄像头，灯带维持待机光。若直接终止服务进程，串口停止发帧，控制器会在 2.5 秒接收超时后恢复固件原有的内置灯效。
* **物理寻址校验**：脱机排查接线与通道顺序时，先停止服务，执行 `./run_test.sh --pixels --seconds 15`。该命令以 25% 亮度依次输出红蓝分区、空间渐变与移动绿区图案，单项持续 15 秒，校验完毕后重启 `./run.sh` 恢复服务。

## 故障排查

| 现象 | 检查方法 |
| --- | --- |
| 串口无权限 | 检查当前进程用户的 `id`；加入组后重新登录或重启服务 |
| 没有设备／设备繁忙 | 检查数据线和固定路径，关闭串口终端、刷机工具及其他 Demo 进程 |
| 灯珠数量不一致 | 同时核对 WLED 设置、实际灯带和 `led_count`，不要只改一端 |
| 能连接但颜色不对或不亮 | 检查 WLED 的 GPIO、灯带类型、颜色顺序、总亮度、实时设置及电源 |

协议参考：[WLED 串口接口](https://kno.wled.ge/interfaces/serial/)、[控制器仓库](https://github.com/wuxx/WLED-Controller-S2)。

## 电流对齐

`current_alignment.targets_ma` 为三档 WLED 电流估算目标 `[220, 450, 700]`（单位 mA）。标定参数为 `controller_bri=128`、`led_ma=55`、`reserve_ma=120`、`limit_ma=850`，对应当前 60 颗 RGB 灯带。

估算公式：

$$
I_{\text{est}} = \text{reserve\_ma} + \left\lfloor \frac{\sum \text{RGB} \times \text{led\_ma} \times \text{controller\_bri}}{765 \times 255} \right\rfloor
$$

在当前默认标定下展开为：

$$
I_{\text{est}} = 120 + \left\lfloor \frac{\sum \text{RGB} \times 55 \times 128}{765 \times 255} \right\rfloor
$$

后端保持 RGB 配比，搜索使量化后估算值最接近目标的缩放值，最大缩放不超过 1；灯珠数量或颜色导致目标不可达时输出可用最大值。

日常输出使用 USB Adalight 二进制帧。串口连接时核对总亮度、限流和灯珠数量；不匹配时停止接管并提示。更换灯带、调整 WLED 每颗电流参数、固件或总亮度后需要重启 Demo。

WLED 回报包含 120mA 控制器预留量。400 毫秒过渡平滑生效，目标电流针对稳定后的输出。当前采用整灯统一电流预算，暂未按多人情绪分布动态拆分电流。
